// PHP Assignment 1

PHP & MySQL course, Jamhuriya University. Ten small programs, one per file.

// How to run

Start Apache in XAMPP, then open `http://localhost/php/Assignment1/<file>.php`.

// Files

| File | What it does |
|------|--------------|
| q1_greatest_smallest.php | Finds the biggest and smallest of three numbers without min/max |
| q2_divisible_3_5.php | Says if a number divides by 3, 5, both, or neither |
| q3_odd_even.php | Odd numbers 2 to 20, then even numbers 35 down to 7 |
| q4_divisible_2_and_5.php | Numbers from 50 to 2 that divide by both 2 and 5 |
| q5_reverse_number.php | Reverses a number with math, no strrev |
| q6_lcm.php | LCM of two numbers (8 and 12 gives 24) |
| q7_hcf.php | HCF of two numbers (18 and 24 gives 6) |
| q8_multiplication_table.php | 12 by 12 table built with nested loops |
| q9_prime_check.php | Checks if a number is prime |
| q10_primes_10_to_50.php | Lists the primes between 10 and 50 |

To try other inputs, change the values at the top of each file.
